# 한국어 성인 대화용 KoGPT2

SKT KoGPT2와 SexyGPT의 병합 모델을 기반으로 성인 연애, 친밀감, 직설적인 성인 대사 및 일상 대화 예시 30개를 9회 학습했습니다. 별도의 캐릭터 말투나 고정 끝맺음을 학습에 사용하지 않았습니다. 실행기에 주제별 응답 필터가 없습니다.

파이썬에서 `pip install torch transformers==4.57.1 safetensors`를 실행한 뒤 압축을 풀고 `python chat.py`를 실행하세요. 모델 파일은 로컬에서 읽고, 각 질문은 독립적으로 처리합니다. 종료 명령은 `/종료`입니다.

저장한 FP16 모델을 다시 읽어 성인 대화 질문 두 개와 일상 질문 한 개에서 한국어 생성을 확인했습니다. 일부 답변은 요구한 표현을 완곡하게 바꾸거나 질문의 세부를 놓쳤습니다. 모든 요청에 답하는 특성은 검증되지 않았습니다.
